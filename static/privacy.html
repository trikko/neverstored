Privacy

Last updated: September 14, 2026

This service is designed to be as simple and respectful as possible: it does not install cookies, does not profile you, and does not track you across the web.

Cookies and tracking

The site does not install cookies, does not use statistical analysis tools (like Google Analytics), nor pixels or tracking technologies. There is no cookie banner because there is no need for one.

Data you provide

Secrets are encrypted in the browser and transmitted through the server to the recipient. The server only sees encrypted bytes and public keys. Nothing is written to disk: there is no database, no queue, and no storage. Everything is kept in memory and wiped immediately after it is transferred, or when the room expires.

Data collected automatically

Like any web server, for technical and security reasons the server software records some data from each request in its logs (date and time, requested page, outcome). The IP address is recorded only in an anonymized form and logs are kept for a maximum of 14 days, then automatically deleted. They are not used to identify or profile you.

The service also sees the IP addresses when an exchange happens to enforce rate limits. It keeps neither: the IP address that opened the room is counted in memory under a keyed hash. The key for this hash is made at startup, never leaves memory, and dies with the process.

Data Controller and contacts

The Data Controller is Andrea Fontana. For any requests regarding this policy, you can write to the dedicated privacy mailbox: compose the address using the word privacy, followed by the at symbol (@), and finally the domain of this site (neverstored.com).

Right to complain

If you believe that your data is processed in violation of personal data protection rules, you have the right to lodge a complaint with the Data Protection Authority (e.g., via www.gdpr.it in Italy).

Changes

If the site should change (for example, by adding tools that collect data), this policy will be updated accordingly, with the new date at the top of the page.
