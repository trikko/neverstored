neverstored

This instance is misconfigured

Requests are arriving without an X-Forwarded-For header, so this server cannot tell one visitor from another and will not open rooms: a single visitor could otherwise fill its memory for everybody.

Whoever runs it should have the reverse proxy pass the address it accepted the connection from. There is a Caddyfile and an nginx example in deploy/. An instance deliberately run with no proxy in front of it wants NEVERSTORED_NO_PROXY=1 instead, which drops the per-visitor limit along with the requirement.

Open source. Run your own.
